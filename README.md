# 🌪️ Dust Risk Analyzer
### نظام تحليل مخاطر الغبار والإنذار المبكر — منطقة حائل

منصة ويب تفاعلية تحلل السجلات المناخية اليومية لمنطقة حائل منذ 2015، وتتنبأ بأيام الغبار، وتحوّل التوقع إلى **إنذار من أربعة مستويات** مع إرشادات صحية لمرضى الربو والأطفال والسائقين.

🔗 **التطبيق المباشر:** _ضع هنا رابط تطبيق Streamlit_
📊 **العرض التقديمي:** _ضع هنا رابط أو اسم ملف العرض_

> مشروع مقدّم في هاكاثون **مبادرة مسارات الذكاء (Ai pathways)**.

## ✨ المميزات

| التبويب | الوصف |
|---|---|
| **نظرة عامة** | مؤشرات رئيسية، اتجاه هبات الرياح، وترتيب الأشهر والسنوات حسب أيام الغبار المتوقعة |

| **المحاكي** | اختر الحرارة وسرعة الرياح وهبات الرياح لترى احتمال الغبار من الأيام المشابهة تاريخياً |
| **التحليل** | فلاتر زمنية، خريطة حرارية (شهر × سنة)، رسم تشتت، وجدول قابل للتحميل CSV |

## 🗂️ البيانات

الملف: `hail_dust_predictions.csv` (سجل يومي لمنطقة حائل منذ 2015)

| العمود | الوصف |
|---|---|
| `time` | تاريخ اليوم |
| `temperature_2m_max` | درجة الحرارة العظمى (°م) |
| `wind_speed_10m_max` | أقصى سرعة رياح |
| `wind_gusts_10m_max` | أقصى هبات رياح (المؤشر الأساسي لعواصف الغبار) |
| `predicted_dust` | مخرج النموذج: `1` غبار متوقع، `0` لا غبار |

- مصدر البيانات: _اكتب هنا مصدر البيانات المناخية_

## 🧠 النموذج

- **المهمة:** تصنيف ثنائي لكل يوم (غبار متوقع / لا غبار) اعتماداً على الحرارة العظمى وسرعة الرياح وهبات الرياح.
- **الخوارزمية:** _اكتب هنا اسم الخوارزمية المستخدمة_
- **الأداء:** ROC-AUC = **0.985**
- **ملاحظة:** التطبيق يقرأ مخرجات النموذج الجاهزة من ملف CSV، ولا يدرّب النموذج داخله.

## 🚦 مستويات الإنذار

| المستوى | الشرط |
|---|---|
| ✅ آمن | لا غبار متوقع وهبات الرياح دون حد المراقبة |
| 👀 مراقبة | هبات الرياح ≥ الشريحة الربعية الأولى لهبات أيام الغبار، بدون توقع غبار |
| ⚠️ تحذير | النموذج يتوقع غبار |
| 🚨 خطر | غبار متوقع مع هبات رياح ≥ الشريحة الربعية الثالثة لهبات أيام الغبار |

الحدود تُحسب تلقائياً من التوزيع التاريخي لهبات الرياح في أيام الغبار المتوقعة (دالة `risk_level` في `app.py`).

## ▶️ التشغيل محلياً

يتطلب Python 3.10 أو أحدث.

```bash
# 1) انسخ المستودع
git clone <رابط-المستودع>
cd <اسم-المجلد>

# 2) (اختياري) بيئة افتراضية
python -m venv .venv
source .venv/bin/activate        # ويندوز: .venv\Scripts\activate

# 3) ثبّت المكتبات
pip install -r requirements.txt

# 4) شغّل التطبيق
streamlit run app.py
```

يفتح التطبيق على `http://localhost:8501`.

## ⚠️ حدود المشروع

- أيام الغبار **متوقعة** من النموذج وليست رصداً فعلياً.
- المحاكي تقدير إرشادي مبني على أيام مشابهة في السجل، وليس مخرج النموذج نفسه.
- الإرشادات الصحية عامة ولا تغني عن استشارة الطبيب.

## English Summary

**Dust Risk Analyzer** is an interactive Streamlit dashboard for early warning of dust storms in the Hail region (Saudi Arabia). It analyzes daily climate records since 2015 (max temperature, max wind speed, max wind gusts), uses a predictive model (ROC-AUC 0.985) to flag expected dust days, and converts predictions into a four-level alert (Safe, Watch, Warning, Danger) with health guidance for asthma patients, children, and drivers.

**Run locally:** `pip install -r requirements.txt` then `streamlit run app.py`.
